# 三角洲密码工具（重构版）

> 基于 [DeltaForcePwdTool](https://github.com/binbin-miao/DeltaForcePwdTool) 全面重构
> By：Quinlan　Qq：704979478

整合**摩斯密码识别**与**指纹密码破解**，辅助完成《三角洲行动》骇客电脑小游戏。
程序仅读取屏幕截图，不修改任何游戏数据、不做内存读写。

> [!WARNING]
> 本项目仅供 Python 图像处理与自动化技术的交流学习使用。使用本工具产生的任何后果
> （包括但不限于账号风险）由使用者自行承担。

## 重构亮点（v4）

| 项目 | 原版 | 重构版 |
| --- | --- | --- |
| OCR 引擎 | 微信 OCR（wcocr.pyd，必须装微信并登录） | **本地离线 RapidOCR（PP-OCRv3，模型放程序同级 models/）** |
| 运行环境 | Python + 管理员权限（keyboard 库） | **独立 EXE，双击即用，无需 Python、无需管理员** |
| 界面 | 控制台黑框 | **可视化深色主题 UI + 系统托盘 + 结果悬浮提示** |
| 热键 | F5 / F6 / End | **`~` 手动扫描、F7 暂停/恢复、F8 完全退出、F 游戏交互触发** |
| 自动识别 | 热键手动触发一次 | **游戏内按 F 交互后多帧检测：摩斯/指纹界面立即破译，物资/盒子场景 3 秒自动跳过** |
| 识别校验 | 无 | **符号数量校验 + 多帧投票 + 两帧稳定性比对 + 置信度门槛，误识别自动拒绝输入** |
| 日志 | 生成 temp 截图/标注 | **零落盘：不生成、不写入任何日志文件** |
| 学习 | 无 | **自主学习缓存（界面特征签名/人名纠错记忆，越用越快）** |

## 快速开始

```text
方式一：直接运行 dist/三角洲密码工具/三角洲密码工具.exe
方式二：python main.py
```

程序目录结构（EXE 同级）：

```
三角洲密码工具/
├── 三角洲密码工具.exe     # 主程序
├── models/                # 本地 OCR 模型（离线识别）
├── images/                # 指纹模板（按角色分目录）
```

## 热键一览

| 热键 | 功能 |
| --- | --- |
| `~`（反引号） | 手动触发单次密码界面扫描 |
| `F7` | 暂停 / 恢复自动识别 |
| `F8` | 终止程序所有相关进程，完全退出 |
| `F`（游戏中） | 交互触发自动检测（仅游戏窗口在前台时生效） |

所有热键可在 UI「热键自定义」面板中修改，点击「应用热键」后全局生效；
「全局热键总开关」可一键关闭全部热键。

## 自动识别逻辑（重点修复）

```
游戏内按 F 交互
  └─ 前台窗口校验（防误触）→ 启动多帧检测循环（默认每 0.5s 采样一次）
       ├─ 检测到摩斯界面 → 立即破译：多帧投票 → 数字校验 → 自动/手动输入
       ├─ 检测到指纹界面 → 立即破译：人名OCR纠错 → 模式判定 → 模板匹配 → 稳定性校验 → 自动点击
       └─ 3 秒内未出现密码界面 → 判定拾取物资/开盒场景，直接跳过
未检测到界面时，可随时按 ~ 手动扫描
```

相比原版修复的关键缺陷：

1. **检测时机过早**：F 交互后动画约 1.5s 密码界面才渲染完成，原版立刻截图导致识别失败；
   新版按采样间隔持续检测至界面出现。
2. **摩斯误识别**：新增符号数量严格校验（必须恰 5 个符号且命中字典才解码），
   多帧投票一致才输出，宁可不输、不乱输。
3. **指纹偶发错误/无法识别**：人名 OCR 多倍放大 + 两级纠错 + 学习缓存；
   匹配增加直方图均衡化预处理与全局最优指派；两帧稳定性比对后再点击。
4. **安全门控**：人名未确认 / 数字未读取 / 界面纹理不符 / 匹配分数不足时
   **一律不自动点击**，改为在 UI 输出建议点击方案，避免误点击。

## 配置说明（config/settings.json）

坐标以 2K(2560x1440) 为基准，程序启动时自动按当前分辨率等比缩放。

| 字段 | 说明 |
| --- | --- |
| `hotkeys` | 手动扫描 / 暂停 / 退出 / 游戏交互键 |
| `detect_timeout` | 密码界面检测超时（秒，默认 3.0） |
| `sample_interval` | 动态画面采样间隔（秒，默认 0.5） |
| `center_scan` | 中心区域识别（默认开启，仅截取扫描框，降低性能消耗） |
| `fingerprint.match_threshold` | 模板匹配置信度（0.3~0.9） |
| `fingerprint.name_threshold` | 人名确认置信度 |
| `morse_auto_input` | 摩斯识别后自动输入（默认关闭） |
| `fingerprint_auto_click` | 指纹识别后自动点击（默认开启，安全门控保护） |
| `morse_confirm_clicks` | 摩斯输入后确认点击坐标列表 |
| `regions` | 摩斯码 3 个识别区域 |
| `fingerprint.*` | 人名区 / 数字区 / 候选格 / 模式配置 |
| `ui.learning` | 自主学习开关（经验缓存写入 experience.json，可关闭） |

- UI「配置与学习」卡片支持：导出配置 / 导入配置 / 重置默认 / 清空学习缓存。
- 「识别区域记忆锁定」开启后可防止误改配置。

## 指纹识别详解

```
识别人名（OCR+纠错） → 数字区取最大值定模式（A简单4 / B普通6 / C困难8）
→ 加载 images/<人名>/ 模板 → 候选格直方图均衡化+多尺度模板匹配
→ 按模板编号 1..N 顺序点击（分数最优指派）→ 确认点击
```

指纹模板目录（images/）按角色名分子目录，1.png、2.png……（最多 8 张）。
新增角色模板可直接放入对应目录。
